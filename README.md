# Magyar Politika
A Civilization 1-style Hungarian party simulator (Flask + vanilla JS). Game values are simplified, not exact history.

Run locally: `pip install -r requirements.txt` then `python app.py` and open http://127.0.0.1:5000

Deploy on Render (Web Service from this GitHub repo):
- Build command: `pip install -r requirements.txt`
- Start command: `gunicorn app:app`

Keys: Space = pause, 1 / 2 / 3 = 1x / 2x / 4x speed.
